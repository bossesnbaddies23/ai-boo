# AI Boo

Open-source personalized AI avatar platform with subscription pricing, branded experiences, and customizable avatar features.

## Goals

- Build a branded AI companion experience rooted in identity and user control
- Include subscription and premium upgrade flows
- Support avatar animation and motion states
- Keep everything open source and deployable
- Create a foundation for a future AI assistant stack

## Stack

- React + Vite
- Express backend
- Tailwind CSS
- Open-source friendly by default

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm start
```
